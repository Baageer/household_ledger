# 家庭 AI 记账微信小程序——产品定位与功能体验

## 1. 产品定位

### 产品名称（暂定）

**家账——家庭 AI 记账助手**

### 核心定位

不是简单的“手动记账工具”，而是：

> **导入支付宝、微信和银行卡账单，AI 自动帮全家整理收支。**

核心价值：

- 家庭成员共同管理家庭收支
- 支持多个资金账户
- 支持支付宝、微信、银行卡账单导入
- 自动去重、识别账户间转账和退款
- AI 自动分类与商户标准化
- 支持自然语言记账和 OCR 截图记账
- 提供家庭预算、收支统计和财务分析

## 2. 产品总体目标

用户不需要每天手动记录大量交易，只需要：

```text
支付宝账单 / 微信账单 / 银行账单 / 截图
                 ↓
                导入
                 ↓
             统一交易模型
                 ↓
          去重 / 转账 / 退款识别
                 ↓
             AI 自动分类
                 ↓
               用户确认
                 ↓
               家庭账本
                 ↓
             统计 / 预算 / 分析
```

产品原则：AI 负责解析和建议，正式入账必须经过用户确认。

### MVP 数据获取策略

第一版不建议直接连接支付宝、微信或银行账户 API。金融数据涉及敏感个人信息、平台权限和合规要求，优先采用：

- 手动记账
- 账单文件导入
- 账单截图 OCR
- 自然语言记账

未来再根据平台开放能力和合规要求评估账户连接。

## 4. 账单来源与用户流程

### 手动记账

用户直接输入收入、支出或转账，例如：

```text
收入：+10000
支出：-35
分类：餐饮
账户：微信
```

### 支付宝、微信账单导入

```text
支付宝 / 微信
       ↓
用户导出 CSV / Excel
       ↓
上传并解析
       ↓
标准化、去重、分类
       ↓
用户确认
       ↓
正式入账
```

### 银行账单导入

支持 CSV、Excel；PDF 和 OCR 截图作为增强能力。建议先完成结构稳定的 CSV/Excel 解析，再扩展复杂格式。

### OCR 截图记账

```text
支付宝 / 微信 / 银行 APP 截图
              ↓
          OCR / 多模态模型
              ↓
识别时间、商户、金额、收支方向
              ↓
          AI 分类并给出置信度
              ↓
              用户确认
              ↓
              正式入账
```

## 5. 核心页面与交互

底部导航保持四项：

```text
┌────────┬────────┬────────┬────────┐
│  首页  │ 账单   │ 统计   │ 我的   │
└────────┴────────┴────────┴────────┘
```

### 首页

回答“这个月家庭财务怎么样”，展示本月收入、支出、结余、支出分类排行和各分类预算使用率。

```text
收入 ¥28,600     支出 ¥12,860     结余 ¥15,740

住房 ¥4,500  餐饮 ¥2,360  购物 ¥1,820  交通 ¥620
餐饮预算 72%  购物预算 91%
```

### 账单页面

按月份汇总收入和支出，按日期展示交易明细，并提供右下角“＋记一笔”入口：

```text
2026年8月
收入 ¥28,600 / 支出 ¥12,860

今天
19:32 美团外卖 -¥56
18:20 滴滴     -¥32
12:15 星巴克   -¥36

昨天
09:00 工资     +¥28,000
```

### 手动记账页面

字段包括：交易类型（支出/收入/转账）、金额、分类、账户、成员、备注和时间。

```text
支出 / 收入 / 转账
¥128
分类：餐饮    账户：微信    成员：爸爸
备注：晚饭
[保存]
```

### AI 自然语言记账

输入“今天晚上和老婆吃火锅花了328，用微信支付”，AI 解析为：

```json
{
  "type": "expense",
  "amount": 328,
  "category": "餐饮",
  "subcategory": "聚餐",
  "account": "微信",
  "member": "我",
  "date": "2026-08-27"
}
```

确认卡片展示分类、账户和金额，用户点击“确认”后才入账，也可以修改解析结果。

### 统计页面

MVP 提供四类统计：收支趋势（按日/周/月）、支出分类占比、家庭成员支出汇总、分类预算使用情况。

### 我的页面

```text
家庭：我的家庭
账户：支付宝、微信、招商银行、现金
账单导入：支付宝、微信、银行卡
分类管理 / 预算管理 / 家庭成员
数据安全 / 导出账本
```

### 账单导入与确认

用户选择支付宝、微信、银行卡或截图识别，导入过程中显示交易总数、收支数、转账数、重复数、已分类数和待确认数；对低置信度交易提供“正确/修改”，并支持“全部确认”。

## 6. 分类体系

第一版避免设计几百个分类，建议使用有限的收入和支出分类。

收入：工资、奖金、投资收入、兼职、红包、退款、其他。

支出：住房（房贷、房租、物业、水电）、餐饮（早餐、午餐、晚餐、外卖、聚餐）、交通（公交、地铁、打车、加油）、购物（日用品、服装、数码）、娱乐（电影、游戏、旅游）、教育、医疗、保险、通讯、其他。

## 7. 产品竞争力与后续方向

单纯“家庭记账”竞争力较弱，更合适的定位是：

> **AI 自动整理家庭财务。**

核心闭环是多来源账单和自然语言/OCR 输入，经过统一交易、去重、转账识别、AI 分类后形成家庭账本，再提供预算和财务分析。

第二阶段可增加家庭资产负债、智能预算和 AI 财务分析；暂不做股票实时行情、基金分析、理财/投资建议、贷款、信用评分及复杂社交功能。
